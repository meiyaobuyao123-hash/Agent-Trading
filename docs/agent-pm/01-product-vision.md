## 1. Mission Statement

**让每个加密链上现货投资者都有一个懂自己、记得住、能陪伴完整交易周期的 AI Copilot。**

信号层要**和 Photon / Maestro 一样快**（毫秒级感知、秒级生成 thesis），但不止于快——我们在"快"之上加三件事：**可解释的分析、持续的记忆、从发现到复盘的闭环**。不是慢速的分析工具，也不是没有大脑的信号机器——是既快又有判断力的交易 Copilot。

---

## 2. Problem Statement

加密链上现货投资者（不管小白还是老手）每天都面对 4 个痛点：

### 2.1 信息碎片化
用 DexScreener 看价，切 Telegram 收信号，切 Nansen 追聪明钱，切 TradingView 看技术面，最后切 Excel 记账。**5 个工具来回切，每天浪费 1-2 小时在切换上**。

### 2.2 AI 没有记忆
ChatGPT / Claude 能分析单次问题，但**不记得你过去的交易、偏好、失败教训**——每次都从零解释。真正有价值的"你这次情况跟 3 周前 X 代币很像"永远说不出来。

### 2.3 信号到执行的断层
看到好信号 → 切钱包 → 切 DEX → 手动调滑点 → 漏了个参数 → 错过机会。**每个交易循环有 5-8 次上下文切换**。

### 2.4 亏钱没复盘
输了继续 FOMO，赢了不知道怎么复制。**散户唯一的学习机会（自己的交易数据）被浪费**。

## 3. Product Principles

指导后续所有产品决策的 5 条原则：

| # | 原则 | 含义 |
|---|------|------|
| P1 | **快速 + 可解释并重** | 信号感知毫秒级、thesis 生成秒级（速度不让步）；每条建议都有完整解释链路（数据源 / 分析逻辑 / 历史案例）。"快"不等于"黑盒" |
| P2 | **记忆驱动成长** | Agent 记住每次决策/反馈/结果。一周后比第一天精准，一个月后比用户自己更懂自己的交易偏好 |
| P3 | **人机协作默认保守，授权后可自动** | Agent 默认给建议 + 小额自动执行；大额决策等用户拍板。**若用户明确授权特定策略/代币/额度，可在授权范围内自动执行**（授权必设额度上限 + 时效 + 白名单，随时可撤回） |
| P4 | **从发现到复盘的闭环** | 6 大能力（查 → 分析 → 策略 → 模拟 → 回测 → 复盘）无缝衔接。不做单点最强，做串联最好 |
| P5 | **默认保守** | 新用户默认模拟盘；高级选项需主动开启；保护本金优先于最大收益。信任一旦崩一次就再也回不来 |

## 4. North Star Metric

**每周完成至少 1 次"闭环"的用户比例**

> 闭环 = 打开 thesis → 做出决策（采纳/拒绝）→ 记录结果反馈（自动或手动）

为什么选这个：
- **不是 DAU**（虚荣指标，可能只是刷着玩）
- **不是 PnL**（短期加密行情波动大，容易被数据污染）
- **是真实使用深度 + 反馈完整度** ——用户愿意让 Agent 记他的行为，说明真在用

**目标**：
- v1 MVP（M3）：种子用户中 50% 达成
- 1 年：活跃用户中 70% 达成
- 3 年：行业标杆，定义"Copilot 深度使用"标准

## 5. Secondary Metrics

辅助指标，分 3 组，不能与 North Star 冲突：

### 5.1 用户参与（Engagement）

> ⚠️ 当前无真实用户，目标为推测。M1 首批用户后校准。

| 指标 | 含义 | 目标（⚠️ 推测）| 校准依据 |
|------|------|------|---------|
| Thesis 采纳率 | 用户点"采纳" / 去模拟盘下单的比例 | ≥ 30% | 参考 AI 推荐系统 CTR 均值 20-35% |
| 反馈率 | 用户主动点赞/点踩/评论 thesis 的比例 | ≥ 40% | 偏高，看产品 UX 简化程度 |
| 复盘阅读率 | 周报/月报被打开率 | ≥ 50% | 邮件周报打开率一般 20-30%，App 内推送可更高 |

### 5.2 用户留存（Retention）

> ⚠️ **当前无真实用户数据**（device_tokens = 0）。目标均为推测值，需在 M1 首批 50-100 种子用户后校准。

| 指标 | 含义 | 当前 | 目标（⚠️ 推测）|
|------|------|------|---------------|
| 7d 留存 | 新用户 7 天后仍活跃 | 0（无用户）| 参考 AI 产品行业均值 40-50%；我们目标 ≥ 50%（偏高，有风险）|
| 30d 留存 | 新用户 30 天后仍活跃 | 0 | ≥ 30%（行业均值 15-25%）|
| 自建策略数 | 平均每活跃用户自建策略数 | 13 条 / 1 开发者用户 | ≥ 2（推测）|

**校准节点**：M1（首批 50 用户上线后 1 月）→ 本数字全部用真实数据替换，目标重新设定。

### 5.3 策略质量（Strategy Quality）⭐ 核心能力验证

用户核心价值：**策略是否真被用起来 + 策略是否真能赚钱**。策略层指标差 = 产品价值破产。

> 📊 **基于 2026-04-23 生产数据的真实 baseline**（非推测）。目标基于 baseline 上调 15-30%，数据来源：`hot_sim_trades` 表 6k+ 条闭仓记录。

| 指标 | 当前 baseline（真实）| v1 目标（上调） | 说明 |
|------|---------------------|--------------|------|
| **信号策略命中率** | 🟡 待接入（无历史 D1 追踪数据） | D1 涨幅 > 10% 占比 ≥ 40% | 需先实现信号后续追踪机制 |
| **Hot 策略胜率** | **42% (repeat) / 45% (unique)** | **≥ 48% 稳定** | Hot 当前弱势，v1 目标先超越随机 50% 的对称期望 |
| **Smart Money 胜率** | **44%** | **≥ 48% 稳定** | 胜率不高但盈亏比健康，总期望正 |
| **Pump 胜率** | ⚠️ 0 闭仓 / 937 open（刚上线）| 首批闭仓后定 baseline | v1 先跑出 50 个闭仓再定目标 |
| **Hot 策略盈亏比** | **1.10 : 1**（+15.86% / -14.48%）🔴 期望值**负** | **≥ 1.3 : 1** | 当前 Hot 每笔期望 -1.74%，是产品**致命问题**，优先修复 |
| **Smart Money 盈亏比** | **2.12 : 1**（+24.87% / -11.74%）✅ | **保持 ≥ 2.0 : 1** | 健康（每笔期望 +4.37%），是现在产品唯一正期望来源 |
| **单笔期望值**（核心）| Hot: -1.74% / SM: +4.37% | **所有 source ≥ +1%** | 比胜率 / 盈亏比更本质的指标 |
| **策略存活天数（中位数）** | 🟡 功能未上线，待埋点 | ≥ 14 天 | v1 上线后 M1 收集首批真实数据 |
| **策略编辑迭代次数** | 🟡 功能未上线 | ≥ 3 | 同上 |
| **回测使用率** | 🟡 功能未上线 | ≥ 60% | 同上 |

**策略质量红线**：
1. **Hot 期望值 < 0** 持续 2 周 → 优先级 P0，拉取 hot_coin_optimizer 整改
2. **任一 source 单笔期望值 < 0** 持续 1 周 → 触发该 source 暂停真实执行（仍保留模拟盘）
3. **Pump 首批 50 笔闭仓期望值 < 0** → 回滚至关闭 pump sim

**注释**：
- 🔴 红色 = 当前生产数据达不到行业基准
- 🟢 绿色 = 达标或超出
- 🟡 待数据 = 功能未上线 / 埋点未完成，等真实数据

## 6. Non-goals（明确不做）

聚焦的关键，比"做什么"更重要。

### 6.1 产品 Scope Non-goals
- ❌ **合约 / 期货 / 杠杆 / 永续**（只做现货）
- ❌ **CEX 交易**（只做链上 DEX）
- ❌ **借贷 / staking / yield farming**
- ❌ **NFT**
- ❌ **跨链桥集成**
- ❌ **主流币（BTC/ETH/SOL 本体）大额交易**（流动性已成熟，价值有限）
- ❌ **高频交易（< 1 分钟级）**
- ❌ **多账户 / 子账户**（v1）
- ❌ **社交复制交易（social copy trading）**（v1）

### 6.2 技术 Non-goals（不重造轮子）
- ❌ 不自建 DEX 聚合器（用 Jupiter / 1inch）
- ❌ 不自建钱包（对接 Phantom / Rabby / Metamask）
- ❌ 不做自己的行情推送协议（用 Helius / DexScreener）

### 6.3 商业 Non-goals（守住底线）
- ❌ **不承诺盈利**
- ❌ **不做合规限制地区**（CN 等）
- ❌ **不做 tax/audit 报告**（交给专业工具）
- ❌ **不收 vanity 指标货**（不优先 DAU / 下载数）

## 8. Competitive Landscape

| 类别 | 代表产品 | 它们强在 | 我们的差异 |
|------|---------|---------|-----------|
| 链上数据 | Nansen / Arkham | 机构级链上分析 | 给 thesis 而非原始数据表 |
| 行情看板 | DexScreener / GMGN | 代币实时行情 | 加分析 + 记忆 + 闭环 |
| 交易 Bot | Photon / Maestro / Trojan | 快速执行 / 狙击 | **速度相当**（毫秒级感知）+ 加可解释 + 记忆 + 闭环 |
| 技术分析 | TradingView | 图表工具丰富 | 专注链上 + 融合多源 |
| 通用 AI | ChatGPT / Claude | 开放对话 | 专业 + 持续记忆 + 执行能力 |
| 聪明钱追踪 | Birdeye / DexLab | 聪明钱地址监控 | 不只追踪，还解释"为什么" |

### 我们真正不可替代的 2 件事

1. **持续记忆的 Copilot**：别家工具是"外车人"，我们是"快公台弟"——知道你过去 3 个月的每一次决策、反馈、结果，并用这些改进下一次推荐。
2. **完整交易闭环**：查 → 析 → 策 → 模 → 测 → 复。别的工具需要你手动切换 3-5 个系统，我们一条龙。

其他竞品可能某个单点比我们强，但**没有一家同时覆盖"记忆 + 闭环"这两个维度**。这就是我们的护城河。

## 9. Target Users（3 层全覆盖，主打中级）

| 层级 | 资金规模 | 占比 | 产品策略 |
|------|---------|------|---------|
| 小白散户 | $100-$5K | 30% | 简化模式：默认保守、多教育、大白话 thesis |
| **中级投资者** ⭐ | $5K-$50K | 50% | **主打**：全功能开放、术语规范、数据证据充分 |
| 专业交易者 | $50K+ | 20% | 专家模式：开放 API、更少 UI 包装、可自定义深度 |

**产品风格以中级用户为锚点**，小白用简化版，专业用扩展选项。不做"谁都不得罪"的折中产品。

## 10. Business Model

### 10.1 v1 - v1.5：完全免费
- **目标**：冲用户量 + 积累交易数据 + 验证记忆系统价值
- **成本**：LLM + DEX API 成本由产品方承担（见 [13-cost-budget.md](./13-cost-budget.md)）
- **红线**：日均单用户成本 < $0.5（否则烧钱模型不成立）

### 10.2 v2 起逐步变现（3 种路径，按优先级）

| 路径 | 时间 | 形态 |
|------|------|------|
| Pro 订阅 | v2 | $20-50/月：更多自建策略/更精准回测/独享信号/无限复盘 |
| DEX 路由分成 | v2.5 | 对接 DEX 拿返佣，不直接向用户收费 |
| Agent API 开放 | v3 | 专业用户/团队付费调用 API |

**不做的商业模式**：广告 / 卖用户数据 / 代投 / 割韭菜式订阅。

## 11. Success Vision

> ⚠️ **所有数字均为方向性目标，非承诺**。当前用户数 = 0、device_tokens = 0。3 月 / 1 年 / 3 年目标需在 M1 真实用户接入后根据 D1 留存 × 裂变系数重新测算。

### 11.1 3 个月（v1 MVP 完成）

**质量门槛**（必须达到，否则不上线）：
- Hot 策略**单笔期望值转正**（当前 -1.74%，目标 ≥ +1%）
- Smart Money 策略**单笔期望值保持 ≥ +4%**
- Pump 策略首批 50+ 闭仓、期望值 ≥ 0

**用户门槛**（推测目标，可上下浮动 50%）：
- 首批 50-100 种子用户
- 其中 50%+ 每周至少 1 次闭环（见 North Star）
- 完成 16 份 PM 文档 + 5 个关键 eval 套件

### 11.2 1 年（推测目标）
- 用户规模：**1,000-5,000 活跃用户**（区间而非点估计，取决于 v1 D1 留存）
- Pro 订阅首批 50-200 付费用户
- Hot 策略期望值 ≥ +3%、Smart Money ≥ +5%、Pump ≥ +3%
- Agent Memory 有效规则 ≥ 200 条（每周产出 3-5 条新规则）

### 11.3 3 年（长期愿景，非 commitment）
- 成为加密链上现货 Copilot 品类前 3
- 与 Jupiter / 1inch / Uniswap 中至少 1 家深度集成
- 发布"agent-to-agent"协议草案，推动行业透明度标准

**具体用户数 / 付费数预测 ≥ 1 年的**：**全部标为推测，不写**。一线 AI 公司也不会在 Vision 里承诺 3 年用户数。

## 12. 关键前提假设（需要持续验证）

Product Vision 成立的前提：

1. **加密链上现货会持续增长**（而非衰退至 CEX）
2. **用户愿意让 Agent 记住自己的交易行为**（隐私接受度）
3. **LLM 成本持续下降**（支撑免费策略）
4. **监管不禁止 AI 提供交易建议**（美国 / 欧盟 / 东亚）
5. **DEX 生态保持开放**（能拿到链上数据 / 能直连路由）

任一假设破裂需重新评估。每季度复查一次。
