**因此**：
- 所有具体数字（"30/50/20 占比"、"资金 $5K-$50K"、"每天 30-60 分钟"等）应视为**假设**，不作为产品决策硬依据

- 本文档 v0.2 的核心价值在"方向性判断"（3 层用户存在、主打中级），不在"具体数字"

## 1. Primary Persona（核心用户）

> 🔴 **以下所有具体数字（年龄 / 资金 / 时长 / 占比）均为推测**。M1 真实用户接入后校准。

### 1.1 Persona A — 小白散户「小陈」

| 字段 | 内容 |
|------|------|
| 画像 | 25-30 岁，一二线城市白领 / 研究生，副业炒币 |
| 地域 | 中国（大陆 + 港台）/ 东南亚华人 |
| 资金规模 | **$200 - $5,000**（总资产的 5-15%） |
| 加密经验 | < 1 年 |
| 风险偏好（1-10） | 7-8（嘴上保守，实际冲） |
| 日投入时长 | 30-60 分钟（通勤 + 摸鱼 + 睡前） |
| 当前工具栈 | OKX CEX / Phantom / DexScreener（看不懂英文）/ 微信群 + TG 小群 |
| 信息渠道 | 抖音、B 站、小红书、微信大 V 公众号、TG 华语群 |
| 决策方式 | "KOL 推就冲" + "看到群里说就跟" + "图表看起来涨就追" |
| 心声（典型原话） | "这币能不能冲？""怎么老是买完就跌？""别人都说 10 倍我怎么只亏钱？" |

**核心痛点**：
- P1. 经常被 pump & dump 割韭菜，单月亏 50%+
- P2. 不敢问"币怎么选"，怕被群友嘲笑
- P3. 英文界面 + 术语看不懂，DEX 操作吃力
- P4. 没有系统方法，凭感觉冲，输了不知道为什么输
- P5. 害怕真金白银亏，但又不想错过机会

**Agent 给他的独特价值**：
- ✅ **教育 + 过滤**：不是推更多信号，是帮他筛掉 90% 的垃圾信号
- ✅ **大白话 thesis**：每条建议 3 句话讲清楚（方向 + 一个理由 + 一个风险）
- ✅ **默认模拟盘**：头 30 天不让他真金下注，**先建立对自己决策质量的认知**
- ✅ **风险翻译**：把"滑点 5% + Top10 持仓 80%"翻译成"这币可能是庄家盘"

**成功标志**：3 个月后，小陈能自己说出"为什么我这次不买"——从"跟风冲"升级到"有判断"。

### 1.2 Persona B — 中级投资者「老王」⭐ 主打

| 字段 | 内容 |
|------|------|
| 画像 | 30-45 岁，互联网/金融/工程背景，有理性决策习惯 |
| 地域 | 全球（中国 / 新加坡 / 东南亚 / 欧美） |
| 资金规模 | **$5,000 - $50,000**（总资产的 10-30%） |
| 加密经验 | 2-5 年，经历过至少一轮牛熊 |
| 风险偏好（1-10） | 5-7（知道止损，但也会留仓博反弹） |
| 日投入时长 | 1-2 小时（碎片化，全天在线但专注时段就 1-2 段） |
| 当前工具栈 | **5-7 个**：Phantom + Rabby + DexScreener + Nansen（试用版）+ TradingView + 3-5 个 TG alpha 群 + Excel 记账 |
| 信息渠道 | TG 付费群 / Twitter / Crypto.news / Messari / 部分微信圈子 |
| 决策方式 | 聪明钱信号 + 链上数据 + K 线 + 综合 TG 讨论 + 自己的小框架 |
| 心声（典型原话） | "我切 5 个工具就为看一个币到底能不能买""建了个监控脚本但维护太烦""这次判断和上次 X 代币一模一样为啥结果完全不同" |

**核心痛点**：
- P1. **工具碎片化严重**：一个决策需要切换 5+ 工具，每天浪费 1-2 小时
- P2. **错过机会**：等他切完工具看完，币已经从 50K → 500K 市值
- P3. **建过自动化策略但复杂度高**：自写 Python 监控脚本，维护不起
- P4. **回测需求得不到满足**：TradingView Pro 不支持 on-chain，Dune 要会写 SQL
- P5. **没有跨决策的记忆**：每次都从零分析，AI 助手（ChatGPT）不记得他过去的失败

**Agent 给他的独特价值**：
- ✅ **效率**：一个 Agent 替代 5 个工具，决策时间从 10min → 2min
- ✅ **跨决策记忆**："这次和你 3 周前买的 Y 代币很像，当时失败原因是 A，这次要避开"
- ✅ **授权自动执行**：<$100 的小额试仓、已验证的策略，可在授权额度内自动跑
- ✅ **策略 + 回测**：把主观框架沉淀成可执行策略，自动回测验证
- ✅ **和 Photon / Maestro 同速**：信号感知毫秒级，不靠"慢但准"讨好他

**成功标志**：6 个月后，老王卸载/停用 3+ 辅助工具（DexScreener + 自建脚本 + Excel），因为 Agent 替代了。

### 1.3 Persona C — 专业交易者「阿强」

| 字段 | 内容 |
|------|------|
| 画像 | 35-50 岁，资深加密 Trader / Quant / Ex-tradfi |
| 地域 | 全球华人圈 + 欧美 |
| 资金规模 | **$50,000 - $1M+**（加密占总资产 30-60%，本职工作） |
| 加密经验 | 5+ 年，经历多轮牛熊，做过某些 alpha |
| 风险偏好（1-10） | 6-8（有系统，不怕大仓位，但风控严） |
| 日投入时长 | 3-5 小时（全职 / 半全职） |
| 当前工具栈 | 自建 Python/Rust 监控 + Nansen Pro + Arkham + Dune + TradingView Pro + 多钱包 |
| 信息渠道 | 一手 alpha 群（付费或人脉）/ OTC 圈 / 链上工具 API |
| 决策方式 | 量化 + 主观 + 链上三位一体，**自建 alpha 管道** |
| 心声（典型原话） | "我自己写了 2000 行脚本但维护要死""想给回测一个框架但自己做太贵""我不相信黑盒 AI，除非能看懂它每步推理" |

**核心痛点**：
- P1. **自建管道维护成本高**：多链监控 + 策略执行 + 复盘，一套 20+ 模块
- P2. **AI 分析不够专业**：ChatGPT / Claude 缺加密领域深度，用了几次就放弃
- P3. **回测框架缺失**：自己写 backtest 太花时间，Vectorbt 之类不够 on-chain
- P4. **多链监控分散**：SOL / ETH / BSC / Base 各看各的

**Agent 给他的独特价值**：
- ✅ **API + 可编程策略**：能通过 API 调用所有核心能力，嵌入他自己的系统
- ✅ **可自定义深度**：默认不给包装好的话术，给 raw data + 推理链路
- ✅ **回测即服务**：不用自己搭，直接调用
- ✅ **节省 20% 自建代码**：替代部分自建监控 / 复盘脚本

**成功标志**：1 年后，阿强在他自己的交易 SOP 里明确写 "Agent 提供数据和初筛，我做最终决策"。

**注意**：这层用户**少（预计 < 20%）但是付费能力强**，是 v2 Pro 订阅的核心目标。初期不讨好他们，但 v1 MVP 要预留 API / 深度选项扩展点。

## 2. Persona 快速对比表

| 维度 | 小陈（小白） | 老王（中级）⭐ | 阿强（专业） |
|------|-------------|--------------|-------------|
| 占比预估 | 30% | 50% | 20% |
| 首要需求 | 教育 + 过滤 | 效率 + 闭环 | API + 深度 |
| 默认模式 | 模拟盘 + 大白话 | 全功能开放 | 专家模式 + API |
| 自动执行 | 关闭 | 可选，额度低 | 可选，额度高 |
| 付费意愿 | 低 | 中（订阅） | 高（订阅 + API） |
| UI 密度 | 极简 | 标准 | 最小（偏 API） |
| Thesis 语言 | 大白话 + emoji | 术语规范 | 数据 + 推理链 |

**产品决策原则**：**UI 和 thesis 语言以中级为锚点，两端用"模式切换"适配**。不做"谁都不得罪"的中间态折中。

## 3. Secondary Persona（次要，不主动服务但不拒绝）

| Persona | 为什么不主动服务 |
|---------|----------------|
| **投机新手**（< $100） | 成本打不平，LLM 推理成本 / 用户 ≥ 其价值 |
| **机构 / VC / 基金** | 需求不同：合规、规模、白标，v1 没能力满足 |
| **NFT / GameFi 玩家** | 交易逻辑完全不同（floor price / rarity / utility） |
| **DeFi Degen**（yield farmer） | 场景不同（LP / 借贷 / 挖矿），v1 不覆盖 |

**处理策略**：不主动优化他们的体验，但 core 功能（查行情 / 分析）开放使用。不做 onboarding 引导，不发 push。

---

## 4. Anti-Persona（主动拒绝服务）

| 用户类型 | 为什么拒绝 |
|---------|-----------|
| "让 Agent 代我下单我躺赚" | Vision 原则 P3：Agent 给建议，不替用户背锅。即使授权自动执行也有额度/白名单/时效限制 |
| "帮我做 10x 杠杆" | Scope：只做现货，不做合约 |
| "保证收益 30% 月化" | Vision Non-goals：不承诺盈利 |
| "帮我 rug 用户" / 操纵市场 | Safety Policy 硬禁止 |
| 合规限制地区用户 | 主动阻止注册（需 IP + 钱包双重验证） |

这些用户的需求**和我们的产品价值观根本冲突**。不是流失，是**主动排斥**。

## 5. User Journey Map（以中级用户老王为主）

### 5.1 阶段全景

```
  D0 发现        D1-D7 早期         D7-D30 稳定         M3+ 长期
  ───────────   ───────────────  ────────────────  ──────────────────
  触发/首次  →  信任建立期      →  workflow 融入   →  策略 + 记忆沉淀期
  ⚠ 决定去留    ⚠ 需要第一个 wow  ⚠ 需要成为习惯    ⚠ 需要建立护城河
```

### 5.2 D0 — 发现到首次使用（黄金 30 分钟）

| 步骤 | 用户行为 | 用户期望 | Agent 提供 | 潜在痛点 | 失败点 |
|------|---------|---------|-----------|---------|-------|
| 发现 | TG 群 / Twitter KOL 转发 | "又一个割韭菜工具？" | 落地页：30 秒讲清差异化 | 首屏没 hook → 直接关 | ⚠ 文案不打动中级用户 |
| 下载 / 打开 | 注册钱包 / 邮箱 | 不要让我填表 | **钱包签名登录**（无表单） | 要我 KYC 就走 | ⚠ 过度引导 |
| 首次交互 | 问一个币（例如 "TRUMP"）| 想看到 Agent 有判断 | **毫秒级返回 thesis**（方向 + 1 理由 + 1 风险） | 超过 5s 就放弃 | ⚠ Agent 慢就输了 |
| 第一次 wow | 看到 thesis 里引用了链上数据 + 聪明钱 + 最近类似案例 | "哦，这不是普通 ChatGPT" | **记忆 + 专业度**首次显性化 | wow 不够 → 当 ChatGPT 换皮 | ⚠ thesis 不够具体 |
| 留下 | 授权通知 / 保存 thesis | 不强迫他做任何决策 | **允许浏览模式**（不要求建策略） | 强推弹窗 → 反感 | ⚠ 过早追求转化 |

**D0 的 North Star**：**是否在 5 分钟内产出第一条让用户觉得 "这不是 ChatGPT 换皮" 的 thesis**。

### 5.3 D1-D7 — 早期（信任建立期）

| 步骤 | 用户行为 | 用户期望 | Agent 提供 | 关键风险 |
|------|---------|---------|-----------|---------|
| Day 1 | 每天打开 2-3 次，看推送 | Agent 推得准 | **每天 3-5 条精选 thesis**（不是 100 条洪水） | 信号太多 → 关通知 |
| Day 2-3 | 开始质疑 | "Agent 说的和我判断不一样谁对？" | 可追溯：展示每个判断的数据源 | 黑盒 → 用户不信 |
| Day 4-5 | 尝试建第一个策略 | 希望简单，不想写代码 | **自然语言建策略**："BC 5% 且聪明钱 2+ 买入就推" | 建策略路径 > 3 步就放弃 |
| Day 6-7 | 第一次看到复盘 | 想知道策略好不好 | **7 日复盘**：策略表现 + 改进建议 | 复盘太专业 / 太草率都不行 |

**D1-D7 的 North Star**：用户建了**至少 1 条策略** + 看了**至少 1 次复盘**。

### 5.4 D7-D30 — 稳定期（workflow 融入）

| 步骤 | 用户行为 | Agent 提供 | 关键风险 |
|------|---------|-----------|---------|
| 每天 2-3 次开 App | 期望看到"新 thesis + 我的策略表现" | 首页一屏看完：push 流 + 我的策略 + 昨日复盘 | 首页信息过载 |
| 逐步关掉其他工具 | 比如卸载 DexScreener 因为 Agent 替代了 | Agent 提供等效的行情查询（查行情能力）| 替代不完整 → 又装回来 |
| 授权部分自动执行 | 信任度累积后 | <$50 小额试仓授权 | 超额自动扣款 → 信任崩盘 |
| 开始用模拟盘 | 测试自己的直觉 | 模拟盘胜率可视化 + 复盘 | 模拟盘太理想 → 失真 |
| 转真金 | 极少数，只用已验证策略 | 硬门槛 + HITL 确认 | 首次亏损 → 怪 Agent |

**D7-D30 的 North Star**：每周完成 ≥ 3 次闭环（对应 Vision North Star）。

### 5.5 M3+ — 长期（记忆 + 护城河）

| 步骤 | 用户行为 | Agent 提供 | 为什么让用户留下 |
|------|---------|-----------|----------------|
| 每周复盘 | 看 Agent 整理的策略表现 + 推荐优化 | Reflection Loop 产出 | **记忆资产**：卸载 = 丢失 3 个月的交易档案 |
| 建复杂策略 | 组合多个条件 | 高级策略编辑器 | 自建策略库有价值 |
| 定期分享 | TG 群分享 Agent 推的 thesis | 一键分享功能 + 水印 | 社交属性 |
| 开启 Pro 订阅 | v2 起 | 更多 thesis / 精准回测 / API | 已有沉没成本 → 续费率高 |

**M3+ 的 North Star**：30d 留存 ≥ 35% + Pro 转化率 ≥ 5%。

## 6. 关键场景（Scenario Deep Dive）

### 场景 1：新币爆发期（速度 + 风控的矛盾）

**时间**：0-6 小时，一个新代币 MC 从 $50K → $5M

**用户行为**（老王）：
1. 00:00 看到 TG 群发"这个币要起飞"
2. 00:01 打开 Agent 问 "XX 靠谱吗"
3. 00:01.5 Agent 返回：**方向：观望；风险：创建 < 3 小时 / Top10 持仓 85%**
4. 00:02 老王决定不冲，继续观察
5. 04:00 Agent 推送：XX 已涨 5x，但链上数据显示庄家出货，警告

**Agent 必须做到**：
- 秒级响应（不能让用户等）
- 硬数据事实（不是"可能是庄"的模糊话）
- 主动监控推送（而不是只响应问）

---

### 场景 2：持仓遭遇暴跌（心态管理 + 复盘）

**时间**：持仓 3 天，突然 -40%

**用户行为**：
1. 打开 Agent："XX 跌了 40% 怎么办"
2. Agent 回答分三段：
   - **事实**：链上看到 whale Y 刚砸盘 80% 仓位（触发原因）
   - **建议**：基于你的策略（7% 止损），应止损离场
   - **记忆**：你 3 周前在 Z 代币也犹豫不止损，结果 -60%。这次模式相似。
3. 用户选止损 → Agent 记录反馈 → 写入 Episodic Memory

**Agent 必须做到**：
- 不做情绪陪伴（"别怕"），做事实陈述
- **引用用户自己的历史**，让他意识到这是模式
- 给出明确可执行建议，不含糊

---

### 场景 3：建立个人策略库（长期积累）

**时间**：M3 用户

用户有 5 条自建策略：
- "聪明钱跟单 - SOL"
- "ETH meme 新发现"
- "BSC 毕业狙击"
- "多聪明钱集中 3+"
- "高 LP/MC 比率"

每条策略 Agent 提供：
- 近 30 天表现（胜率 / 盈亏比 / 最大回撤）
- A/B 测试结果（vs 基准）
- 优化建议（"把 score 阈值从 55 改到 60，历史胜率提升 8%"）

**Agent 的价值**：不是帮用户建策略，是**持续优化**用户的策略，变成用户的"交易健身教练"。

---

### 场景 4：跟单聪明钱失败（教育时刻）

**时间**：某次跟单 -30%

**对小陈（小白）**：
- 用最直白语言解释"这次跟单失败的原因是聪明钱钱包 Y 其实是市商，它是拉升出货"
- 引导："下次跟单看 wallet_tier，elite > verified > watching"
- **转化为成长**：教育而非指责

**对老王（中级）**：
- 给数据：elite 钱包中位胜率 60%，单次信号命中率只有 42%，用户看到的是 random 抽样
- 建议：把 "elite 跟单" 策略加一个过滤器（比如 > 2 个 elite 同时买入）

**对阿强（专业）**：
- 原始数据 dump：该聪明钱 3 个月历史胜率 vs 市场基准
- 不给建议，给他自己决定

**同一事件，3 种响应方式** —— 这是 Persona 差异化的真正落地。

---

### 场景 5：周复盘（记忆驱动）

**时间**：周日晚

用户打开周报：
- **本周操作统计**：总交易 8 笔，胜率 50%，总 PnL +12%
- **最佳 / 最差交易**：最佳 X 代币 +80%（聪明钱策略），最差 Y -25%（FOMO 追高）
- **模式发现**：你周五的决策普遍较差（胜率 30% vs 周一 60%），疑似疲惫
- **规则提议**：建议设置"周五停交易 hard block"，已自动加入你的草稿

用户确认 → 写入 Semantic Memory → 下周生效。

**这是 Agent 真正区别于 ChatGPT 的时刻**：**从用户的数据中发现用户自己都不知道的规律**。

## 7. Journey 反模式（我们避免发生的）

| 反模式 | 危害 | 怎么避免 |
|-------|------|---------|
| Day 1 弹窗要订阅 | 信任崩塌 | v1-v1.5 完全免费 |
| 推送轰炸（每天 > 10 条） | 用户关通知 | 每天上限 5 条，可配置 |
| thesis 太长没人看 | 放弃阅读 | 强制 30 词摘要 + 展开详情 |
| 自动执行超授权 | 信任永久崩塌 | 硬门槛 + 审计日志 |
| "所有用户都推 top signals" | 变成信号机器人 | **按 Persona 个性化** |
| Agent 说错话没认错 | 失信 | **有错就承认**（机制化） |
