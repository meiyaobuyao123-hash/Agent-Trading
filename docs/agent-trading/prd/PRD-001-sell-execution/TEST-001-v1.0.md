## 一、单元测试

### UT-01: 余额查询

| 用例 | 输入 | 预期 |
|------|------|------|
| SOL 代币余额 | 有效钱包+mint | 返回正确 uiAmount |
| SOL 余额为 0 | 钱包无该代币 | 返回 0 |
| EVM 代币余额 | 有效钱包+ERC20 | 返回正确 balance |
| EVM 无效地址 | 错误地址格式 | 抛 ValueError |

### UT-02: EVM Approve

| 用例 | 输入 | 预期 |
|------|------|------|
| 首次 approve | allowance=0 | 发送 approve tx，返回 tx_hash |
| 已 approve | allowance 足够 | 跳过，不发交易 |
| approve 失败 | 模拟 revert | 返回 error |

### UT-03: 卖出执行

| 用例 | 输入 | 预期 |
|------|------|------|
| SOL 全仓卖出 | sell_pct=1.0 | OKX swap 全部余额 |
| SOL 半仓卖出 | sell_pct=0.5 | swap 50% 余额 |
| EVM 卖出含 approve | 首次卖出 | 先 approve 再 swap |
| 余额不足 | balance=0 | 返回 error "余额不足" |
| 滑点超限 | slippage 实际>设定 | 取消交易 |

## 二、集成测试

### IT-01: 止盈自动卖出

```
前置：创建策略 "买入 SOL 链代币 A，止盈 50%"
步骤：
  1. Agent 自动买入代币 A（$100）
  2. 模拟代币 A 价格上涨 50%
  3. PositionMonitor 检测到止盈条件
  4. 自动触发 execute_sell()
预期：
  - strategy_executions 有买入+卖出两条记录
  - pnl_pct ≈ +50%（扣除滑点）
  - exit_trigger = "take_profit"
```

### IT-02: 止损自动卖出

```
前置：创建策略 "买入 ETH 链代币 B，止损 20%"
步骤：
  1. Agent 买入代币 B（$100）
  2. 代币 B 价格下跌 20%
  3. PositionMonitor 检测到止损条件
  4. 自动触发卖出
预期：
  - pnl_pct ≈ -20%
  - exit_trigger = "stop_loss"
  - 链上 tx 确认
```

### IT-03: 追踪止损

```
前置：策略含 trailing_stop=15%
步骤：
  1. 买入 $100，价格涨到 $200（+100%）
  2. 价格回落到 $170（从峰值回撤 15%）
  3. 触发追踪止损
预期：
  - 卖出价 ≈ $170
  - pnl_pct ≈ +70%（非 -15%，因为从入场算仍是盈利）
```

### IT-04: 手动卖出指令

```
步骤：
  1. 用户发送 "卖掉代币 A 的全部持仓"
  2. LLM Parser 解析为 sell action
  3. 执行卖出
预期：
  - 正确识别持仓代币
  - 执行全仓卖出
  - 返回确认消息
```

## 三、异常测试

### ET-01: 流动性不足

```
步骤：模拟代币流动性 < $1000 时触发卖出
预期：发出告警"流动性不足，卖出可能失败"，仍尝试执行
```

### ET-02: OKX DEX 不支持

```
步骤：代币被 OKX DEX 下架
预期：返回 error，记录失败原因，不崩溃
```

### ET-03: 网络超时

```
步骤：模拟 RPC 广播超时
预期：重试 1 次，仍失败则记录 pending 状态，后续查链上确认
```

### ET-04: 并发卖出

```
步骤：止盈和手动卖出同时触发
预期：只执行一次（第二次发现余额已清零，跳过）
```
