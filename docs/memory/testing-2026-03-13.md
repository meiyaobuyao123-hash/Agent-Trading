### Phase 4（本会话完成）— 高优先级修复

#### CRITICAL
1. **EVM nonce 硬编码为 0** (`trade_executor.py`)
   - 问题：nonce=0 只对钱包首笔交易有效，后续全部失败
   - 修复：新增 `_get_evm_nonce()` 调用 `eth_getTransactionCount` RPC
   - `_sign_evm_tx` 改为 `async def`

2. **to_amount 精度硬编码 6 位** (`trade_executor.py`)
   - 问题：非 USDC/USDT 代币小数位数不同（如 WETH=18）
   - 修复：从 OKX 响应 `toTokenDecimalNum` 动态获取

#### HIGH
3. **Claude API 阻塞事件循环** (`llm_parser.py`)
   - 问题：同步 `client.messages.create()` 阻塞 FastAPI async 循环
   - 修复：`await asyncio.to_thread()` 包装

4. **mark_alert_read 缺 user_id 鉴权** (`action_dispatcher.py` + `routes_agent.py`)
   - 问题：任何人知道 alert_id 即可标记已读（跨用户越权）
   - 修复：新增 `user_id` 参数 + `.eq("user_id", user_id)` 过滤

5. **PriceTickerService 仅追踪 solana** (`market_screen.dart`)
   - 问题：BSC/ETH/Base 代币实时价格不更新
   - 修复：按 chain 分组调用 `startMultiChain(chainAddrs)`

#### MEDIUM
6. **EVM volume_usd 是代币数量非 USD** (`smart_money_tracker.py`)
   - 问题：Etherscan tokentx 返回代币数量，未乘以价格
   - 修复：enrichment 后回填 `volume_usd *= price_usd`，重新聚合信号

7. **Supabase SELECT 缺 5m/4h 字段** (`supabase_service.dart`)
   - 修复：`fetchHotCoins()` SELECT 新增 `volume_5m_usd, volume_4h_usd, price_change_5m, price_change_4h`

8. **Tab 切换状态丢失** (`agent_screen.dart`)
   - 修复：`_ChatTabState` + `_MyStrategiesTabState` 加 `AutomaticKeepAliveClientMixin`
   - `_StrategyCard` 加 `key: ValueKey(s.id)` 避免重复 HTTP 请求

9. **trigger_count TOCTOU 竞争** (`strategy_manager.py`)
   - 修复：优先用 Supabase RPC `increment_trigger_count` 原子递增，fallback 读-增
